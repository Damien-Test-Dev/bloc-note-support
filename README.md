# Bloc-notes (GitHub Pages)

Mini bloc‑notes : écrire, sauvegarder automatiquement (localStorage) et effacer.

**Site :** https://Damien-Test-Dev.github.io/bloc-note-support/

## Fonctionnalités
- Zone de texte
- Autosave avec debounce
- Bouton “Sauvegarder maintenant”
- Bouton “Effacer” (avec confirmation)
- Indicateur d’état + horodatage
